# Tiny French course videos

Rendered video lessons for the Tiny French A1 Unit by Unit course (lessons 3-40). This repo is a copy of the Tiny French YouTube engine (tiny-french-youtube) with a trimmed render workflow, so the videos have their own GitHub Pages site and do not use up the 1 GB limit of the main video site.

Render: Actions > Render course lesson, give script names from `lessons/`. Videos are published to `docs/videos/`.
