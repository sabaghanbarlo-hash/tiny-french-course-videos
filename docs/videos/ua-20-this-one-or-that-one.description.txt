VOCABULARY
ce, cet (SUH, SEHT) - this (masculine)
cette (SEHT) - this (feminine)
ces (SAY) - these
joli / jolie (zhoh-LEE) - pretty, nice
moche (MOHSH) - ugly
pratique (prah-TEEK) - practical
confortable (kohn-fohr-TAH-bluh) - comfortable
trop (TROH) - too (much)
plus… que (plew… kuh) - more… than

GRAMMAR
Ce, cet, cette, ces - This / these changes with the noun: ce plus masculine, cet plus masculine starting with a vowel, cette plus feminine, ces plus plural. To be specific, add -ci and -là: ce pull-ci, cette veste-là.
Trop, très, assez, un peu - These words go before the adjective to change its strength: très grand, assez grand, un peu grand, trop grand. To compare, use plus que or moins que: plus cher que, moins cher que.
