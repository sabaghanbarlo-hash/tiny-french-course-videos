VOCABULARY
grand / grande (GRAHN / GRAHND) - tall, big
petit / petite (puh-TEE / puh-TEET) - short, small
brun / brune (BRUHN / BREWN) - dark-haired
blond / blonde (BLOHN / BLOHND) - blond
les yeux (lay ZYUH) - eyes
sympa (san-PAH) - nice, friendly
gentil / gentille (zhahn-TEE / zhahn-TEEY) - kind
drôle (DROHL) - funny
timide (tee-MEED) - shy

GRAMMAR
Adjectives agree with the noun - Add -e for the feminine and -s for the plural. If the adjective already ends in -e, nothing changes for the feminine: il est drôle, elle est drôle. In the feminine you hear the final consonant: grand sounds like "grahn", grande like "grahnd".
Where does the adjective go? - Most adjectives come after the noun: un ami sympa, une fille brune. A few short, common ones come before: un petit chat, une grande maison. Describe someone with être or with avoir for features.
