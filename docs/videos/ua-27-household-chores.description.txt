VOCABULARY
le ménage (luh may-NAHZH) - housework
la vaisselle (lah veh-SEHL) - dishes
passer l'aspirateur (pah-SAY lah-spee-rah-TUHR) - to vacuum
la lessive (lah leh-SEEV) - laundry
ranger (rahn-ZHAY) - to tidy
les courses (lay KOORSS) - shopping, errands
devoir (duh-VWAHR) - to have to, must
pouvoir (poo-VWAHR) - to be able to, can
après-midi (ah-preh-mee-DEE) - afternoon

GRAMMAR
Devoir + infinitive - Devoir is irregular: je dois, tu dois, il / elle doit, nous devons, vous devez, ils / elles doivent. It is followed by an infinitive: je dois ranger, nous devons faire les courses. In the negative: je ne dois pas travailler.
Faire for chores - French uses faire for most chores: faire le ménage, faire la vaisselle, faire la lessive, faire les courses, faire la cuisine. Passer l'aspirateur and ranger are separate verbs.
